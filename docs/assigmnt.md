# P1: Vectorisation et création de données géographiques à partir de carte scannée / image satellitaire (une commune)

## Description
Conversion d'images satellites haute résolution en données vectorielles pour la gestion du patrimoine d'une commune de votre choix.

## Objectif
Maîtriser le géoréférencement, la vectorisation et l'automatisation du nettoyage par script.

## Plan
1. Géoréférencement  
2. Vectorisation / création de la BDG  
3. Script Python de validation des erreurs topologiques  

## Sources
- Carte scannée  
- Image satellite  
- Plan  

## Livrables
- Carte du territoire choisi  
- BDG / SHP  
- Script Python de validation  
- Rapport technique
