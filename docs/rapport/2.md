
## 4. Géoréférencement de l’image

Le géoréférencement constitue une étape clé du projet, permettant d’associer l’image raster à un système de coordonnées géographiques réel. Cette opération rend possible l’exploitation de l’image dans un environnement SIG et son croisement avec d’autres données spatiales.

### 4.1 Détermination de l’emprise spatiale (Bounding Box)

Pour géoréférencer l’image, nous avons exploité le service de géocodage Nominatim, utilisé par OpenStreetMap. En saisissant simplement le nom de la commune ("El Harrach"), Nominatim retourne automatiquement une *bounding box* (BBOX) correspondant à l’emprise géographique de la zone.

Cette BBOX est définie par quatre coordonnées géographiques :

- Latitude minimale (sud)  
- Latitude maximale (nord)  
- Longitude minimale (ouest)  
- Longitude maximale (est)  

Ces coordonnées définissent un rectangle englobant l’ensemble de la commune.

### 4.2 Principe du géoréférencement

Le géoréférencement a été réalisé en utilisant les quatre coins de l’image raster comme points de contrôle (Ground Control Points - GCPs). Chaque coin de l’image est associé à une coordonnée géographique issue de la BBOX :

- Coin supérieur gauche → (longitude min, latitude max)  
- Coin supérieur droit → (longitude max, latitude max)  
- Coin inférieur gauche → (longitude min, latitude min)  
- Coin inférieur droit → (longitude max, latitude min)  

Cette correspondance permet d’établir une transformation affine entre l’espace image (pixels) et l’espace géographique (coordonnées réelles).

### 4.3 Implémentation

L’implémentation du géoréférencement repose sur l’hypothèse que l’image obtenue après *stitching* est correctement alignée et ne présente pas de distorsions significatives. Ainsi, une transformation linéaire simple (affine) est suffisante pour projeter l’image dans le système de coordonnées géographiques.

Le système de coordonnées utilisé est le système WGS84 (EPSG:4326), qui est le standard employé par OpenStreetMap.

### 4.4 Résultat du géoréférencement

À l’issue de cette étape, l’image raster est correctement positionnée dans l’espace géographique. Elle peut désormais être :

- Visualisée dans un logiciel SIG (QGIS, ArcGIS, etc.)  
- Superposée à d’autres couches de données  
- Utilisée comme base pour la vectorisation
